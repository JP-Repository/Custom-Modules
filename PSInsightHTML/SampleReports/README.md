# Sample Reports

These generated standalone HTML examples are intentionally committed as a small curated set of PSInsightHTML output. All report data is synthetic, produced by the existing demo scripts and sample providers; no live infrastructure collection is used.

| Sample | Coverage | Size (bytes) |
| --- | --- | ---: |
| [Framework Demo](PSInsightHTML-Demo.html) | Core components, charts, tables, evidence drill-down, and interactions. | 267,962 |
| [Composed AD Assessment](PSInsightHTML-Composed-AD-Assessment-Demo.html) | DNS, replication, sites/subnets, groups, and Group Policy in one portfolio with findings and overview. | 3,801,541 |
| [DNS Assessment](PSInsightHTML-DNSAssessment.html) | DNS sample provider with KPIs, charts, filters, and tables. | 440,509 |

Normal runtime reports belong in `Reports/` and remain ignored by Git. This directory is for curated samples rather than every generated output. No logs or temporary artifacts are included.

Download an HTML file and open it locally in a browser to use search, sorting, filters, pagination, evidence actions, themes, and export where present. CSS, JavaScript, icons, and SVG charts are embedded; no external assets or network fetches are required. GitHub may show HTML source or provide a download instead of running the report interactively.

These are static snapshots, not live assessments. The fictional values include reserved example domains, documentation IP addresses, and synthetic private subnet ranges used by the existing providers. The Framework Demo is generated by `Examples/New-DemoReport.ps1`, whose current default output filename is `PSInsightHTML-AD-Assessment-Demo.html`; its curated copy is named `PSInsightHTML-Demo.html`.
